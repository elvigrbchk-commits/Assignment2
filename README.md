# Parrot Keeper Portfolio — Web Technologies Task 4

A responsive single-page portfolio built with HTML5 and CSS3, demonstrating modern layout techniques including **Flexbox** and **CSS Grid**.

## Features

- **Header (Flexbox):** Navigation menu aligned using Flexbox.
- **Main Layout (CSS Grid):** Two-column grid structure with a `2fr 1fr` ratio (Projects area on the left, Sidebar on the right).
- **Project Cards (Flexbox):** Cards styled using Flexbox with vertically aligned content and bottom-anchored buttons (`margin-top: auto`).
- **Footer:** Full-width footer pinned to the bottom of the page.

## Tech Stack

- **HTML5** (Semantic structure: `header`, `main`, `section`, `article`, `aside`, `footer`)
- **CSS3** (Flexbox, CSS Grid, custom styling & positioning)
